차트와 KPI는 선택한 보고서 유형의 해당 기간 값입니다. 반기는 6개월 누적, 분기보고서는 Q1·Q3의 3개월 실적입니다. ROA·ROE는 연환산하지 않은 기간수익률입니다. Q2·Q4 파생 분기는 포함하지 않습니다.

계산 기준 · 결측치 · 원문 및 추출 근거

금액은 원 단위로 저장하고 억 원으로 표시합니다. 결측치는 ‘—’이며 0으로 대체하지 않습니다. 평균 자산·자본은 기초·기말 평균, 연결/별도는 분리합니다. EBITDA는 영업이익+감가상각+무형상각의 보조 정의입니다. CFO−현금 CAPEX=FCF. CAPEX 두 구성요소 중 하나가 누락되면 FCF를 계산하지 않습니다. 당좌자산·이자부차입금·이자비용 등은 정확한 공시 계정이나 검증된 수동 입력만 사용합니다.

ROIC/WACC, DPO/CCC 및 시장가치 지표는 검증 가능한 추가 입력을 확보하지 못하면 미산출입니다. DPO를 매출원가로 대체하거나 당좌자산을 단순히 유동자산−재고로 가정하지 않습니다. YoY 매출증가율의 전년 분모는 양수여야 합니다. 분기 CFO는 누적 차분으로 계산합니다. 공시 원문 접수번호와 API 반환 접수번호가 다를 경우 검토 경고를 표시합니다.
